# 🧠 Samvedna AI

Samvedna AI is an advanced, AI-powered student stress monitoring and alert system designed to track students' well-being, identify stress levels, and provide timely alerts to prevent burnout and mental health crises.

---

## 🚀 Features
- **Real-Time Stress Detection:** Analyzes indicators to monitor student stress levels.
- **Automated Alerts:** Sends prompt notifications to mentors, counselors, or authorities when high stress is detected.
- **Crisis Helpline Integration:** Quick access to support resources and helplines.
- **User-Friendly Dashboard:** Clean and intuitive interface for seamless tracking.

---

## 🛠️ Tech Stack
- **Frontend / Core:** HTML, CSS, JavaScript / Modern Web Technologies
- **AI Integration:** Google AI / LLM integration for analysis and response generation
